# Studio Premium Instrument Sound Credits

GleeWorld Studio's premium ("Studio") instrument sounds are converted from
these free/open-license sample libraries. The converted MP3 sample sets are
served from the `gleeworld-studio` DigitalOcean Space; this file is the
source of truth for the in-app credits page (`public/studio-sound-credits.html`).

| Studio instrument(s) | Library | Author | License |
|---|---|---|---|
| Grand Piano | Salamander Grand Piano V3 | Alexander Holm | [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) |
| Electric Piano | Greg Sullivan E-Pianos (Wurlitzer EP200) | Greg Sullivan (sullivang.net) | [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) |
| Choir Aahs | Fluid (R3) SoundFont | © 2000-2002, 2008 Frank Wen | MIT (notice below) |
| String Ensemble, Violin, Cello Section, Pizzicato | VSCO 2 Community Edition | Versilian Studios LLC / Sam Gossner | CC0 1.0 (credit is a courtesy) |
| Acoustic Guitar (Nylon) | Spanish Classical Guitar (FreePats) | Roberto (zenvoid.org) | CC0 1.0 |
| Pipe Organ | Church Organ Emulation (FreePats), rendered from Aeolus by Fons Adriaensen | Roberto (zenvoid.org) | CC0 1.0 |
| Drum Kit · Studio | MuldjordKit (FreePats stereo edition) | Lars Muldjord; FreePats edition by Roberto (zenvoid.org) | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| Drum Kit · Rock | AVL Drumkits — Red Zeppelin | Glen MacArthur (bandshed.net) | [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) |
| Drum Kit · Jazz | AVL Drumkits — Black Pearl | Glen MacArthur (bandshed.net) | [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) |
| Drum Kit · TR-808 | Roland TR-808 sample set (1994) | Michael Fischer / Technopolis | CC0 1.0 |
| Drum Kit · Trap, 808 Bass | Free Drum Samples (trap/bounce/lo-fi) | Boochi44 (derived from the CC0 TR-808 set) | CC0 1.0 (per repo README) |

The converted sample sets for the CC BY-SA kits (Red Zeppelin, Black Pearl)
are themselves redistributable under CC BY-SA 3.0.

Not shipped: FSS Steel String Guitar (GPL — copyleft unsuitable for
redistribution here); Salamander Drumkit (superseded by MuldjordKit);
Jeux d'orgues (permission-required license).
